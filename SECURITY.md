# Security

Please report a vulnerability by email to support@dexio.wiki, with "security" in the
subject, rather than in a public issue. Include what you found, how to reproduce it,
and the version or commit it affects.

Fixes ship to the hosted service at https://app.dexio.wiki and land in this
repository at the same time.

Please do not test against other people's workspaces on the hosted service. Run your
own copy (see [deploy/README.md](deploy/README.md)) or use a workspace you own.
